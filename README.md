# DanceTorika

## Команда: Мифишки

## Задача: Разработка реабилитационной мобильной игры для пользователей с ампутацией рук с управлением через ЭМГ-датчики

### Описание задачи
В рамках задачи необходимо разработать мобильную игру, которая станет частью реабилитационного процесса для людей с ампутацией верхних конечностей. Управление игрой должно осуществляться с помощью ЭМГ-датчиков, которые считывают мышечную активность пользователя. Игра должна не только развлекать, но и помогать пользователям развивать и восстанавливать мышечную активность, улучшать контроль над протезом и повышать мотивацию к регулярным тренировкам.

### Решение

[Ссылка на презентацию решения](https://disk.yandex.ru/d/AblaskkLWcF2ig)

В рамках решения представленой задачи была детально проработана [визуальная составляющая](https://disk.yandex.ru/d/gP_xzzthxL4JNQ) приложения, механика управления персонажем с использованием ЭМГ=датчиков, а также [разработан один из уровней](https://disk.yandex.ru/d/kYtlU4vbcv7T8A) самой игры.

При первом запуске игры пользователь проходит обучение, а также настраивает работу ЭМГ-датчиков.
